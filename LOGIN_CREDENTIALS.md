## How to Use

1. Open the application
2. You'll see the login page with a modern dark theme
3. Either:
   - **Quick method:** Click one of the four "Quick Login" buttons (Admin, HR, Manager, Employee)
   - **Manual method:** Enter email and password manually
4. After login, you'll be automatically redirected to the role-specific dashboard

## Security Note

This is a demo application with mock authentication. In production:
- Passwords should be hashed
- JWT tokens should have expiration
- HTTPS should be enforced
- API should validate all requests
- Rate limiting should be implemented
